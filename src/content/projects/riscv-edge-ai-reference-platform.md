## Scope

A reference design that a student or engineer can build on without assembling
the whole stack first:

- an FPGA-ready RISC-V core with an attached inference accelerator
- the software side: driver, runtime hooks and a worked example model
- build scripts and a reproducible bring-up path
- measurements to compare against, rather than claims
